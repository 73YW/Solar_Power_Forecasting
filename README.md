
# 基于气象特征的光伏功率预测研究 (Solar Power Forecasting)

## 📖 项目简介
在“碳达峰、碳中和”的双碳战略目标背景下，光伏发电正大规模并网。然而，光伏出力极易受云层遮挡、温度变化等气象因素影响，具有显著的波动性和间歇性。精准的光伏功率预测是电网调度维持发用电平衡、降低火电调峰成本、减少碳排放的核心技术之一。

本项目基于公开Kaggle光伏数据集，利用机器学习与深度学习方法，探究如何利用辐照度、环境温度与组件温度等气象特征，准确预测光伏电站的交流功率。

## 📂 仓库结构
本项目包含完整的从数据清洗到模型评估的科研流程，共分为四个核心代码文件：

*   `读取数据画图.py`：读取Kaggle原始数据，完成时间格式转换、多表内连接、缺失值处理及夜间无效数据剔除，并绘制初步EDA图表（功率曲线、辐照度-功率散点、温度分布）。
*   `基线模型主模型.py`：构建线性回归基线模型与随机森林主模型，按时间顺序切分数据集（防数据泄露），并对比评估MAE与RMSE指标。
*   `天气分场景预测.py`：采用变异系数（CV=标准差/均值）客观划分晴天与阴天场景，分别训练随机森林，探究模型在不同天气下的失效边界。
*   `LSTM.py`：引入长短期记忆网络（LSTM），采用滑动窗口法构建时序数据，尝试深度学习在小样本数据集下的表现，并进行模型适用性反思。
